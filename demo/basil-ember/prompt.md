Build a modern, premium-looking website for Basil & Ember, a neighborhood pizza
restaurant. React + Vite + TypeScript, runnable with `npm install` and `npm run dev`.
Pages: home, menu with categories and dietary filters, item page with sizes and
toppings, cart, pickup checkout (name, phone, pickup time), order confirmation,
table reservations, and about/contact with hours and address. Use made-up menu
data in the code, no backend and no payments. Add a `lint` script and a few
Vitest tests.
