# Submission notes

## Use of Meta products

Fitts runs on Meta's models end to end. **Muse Spark 1.3** is the everyday brain: it holds the
interview, reads the code into an App Model, decides each crawl step, walks journeys from
screenshots, answers in the chat, and fixes code when Muse Code isn't available. **Muse Wonder 1.0**
does the hard judgment: two of the five reviewers, merging their findings, the theme check, the
judge of surprising page changes, and the redesign's directions. **Muse Code**, Meta's coding agent
running Muse Wonder, makes the fixes inside an edit allowlist and does the second pass of
understanding a project. **Muse Spark Open** on Baseten is a full stage, not a token: it's an
independent reviewer in the Quality profile, and in the Open profile it runs every reviewer, the
merging and the theme check. **Muse Image 1.0** draws mockups and redesign illustrations, **SAM 3.1**
outlines the element each finding is about, and **Muse Voice Transcribe 1.0** turns the owner's
voice into commands.
