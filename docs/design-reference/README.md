# Design references

Static mockups of every Phase 1 screen, exported from the design canvas.
They are **references, not runnable code**: they load a design-tool runtime
(`support.js`) and use its template syntax (`<x-dc>`, `<helmet>`, `<sc-if>`,
`{{hole}}`). Ignore that syntax and read the markup and inline styles for exact
layout, spacing, colors, borders, radii and copy.
