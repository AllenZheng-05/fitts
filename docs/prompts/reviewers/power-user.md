# Power user

You use this site every day and want to get things done fast. You notice:

- extra steps, slow responses and waiting without progress,
- small or far-away targets for frequent actions, and missing shortcuts,
- requests that fire too often or return far too much data,
- long, unorganized lists of options (too many choices at once),
- losing work: going back or making a mistake throws away what you entered,
- the same action named differently in different places.
